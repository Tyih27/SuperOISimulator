# Super OI Simulator

Super OI Simulator 是一个以信息学竞赛训练为主题的自动战斗模拟器。玩家从学生名单中选择三名学生，安排 A1、A2、A3 站位，让他们在有限回合内自动解决题目并应对题目的反击。

项目目前处于浏览器战斗原型阶段，使用原生 HTML、CSS 和 JavaScript ES Modules，无前端框架和运行时依赖。

## 当前功能

- 从六名学生中选择三名参战学生
- 编辑 A1、A2、A3 三个固定站位
- 校验人数、重复学生和无效站位
- 使用固定种子执行可复现的自动战斗
- 按 `A1 -> B1 -> A2 -> B2 -> A3 -> B3` 顺序结算行动
- 支持开始、暂停、单步、重新挑战和 `0.5x` 至 `4x` 播放速度
- 展示学生精力、专注值、技能状态、题目进度和事件日志
- 展示胜负结果及战斗统计
- 支持桌面端和移动端布局，并包含基础键盘与屏幕阅读器支持

账号、云存档、主线成长、训练、商店、招募和异步竞技场尚未实现，详见[项目完成计划](docs/superpowers/plans/2026-08-19-project-completion.md)。

## 环境要求

- Node.js 22 或更高版本，用于运行测试
- 任意支持 ES Modules 的现代浏览器
- 一个静态文件服务器

当前版本没有第三方 npm 依赖，因此无需执行 `npm install`。

## 本地运行

在项目根目录启动静态服务器：

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

然后访问：

```text
http://127.0.0.1:8000/
```

页面使用浏览器原生 ES Modules，不建议直接通过 `file://` 打开 `index.html`。

## 操作方式

1. 在“出战准备”区域选择三名学生。
2. 使用下拉框安排 A1、A2、A3 站位。
3. 点击“确认编队”。
4. 点击“开始战斗”自动播放，或使用“单步”逐阶段查看结算。
5. 战斗中可以暂停或调整播放速度；结算后可以使用相同种子重新挑战。

同一个编队、站位、关卡配置和随机种子会产生相同的事件序列，可用于回放验证和数值测试。

## 测试

运行全部测试和 JavaScript 语法检查：

```bash
npm run check
```

仅运行测试：

```bash
npm test
```

也可以单独运行测试组：

```bash
npm run test:combat
npm run test:formation
npm run test:playback
npm run test:task6
```

测试覆盖确定性战斗、回合顺序、编队规则、播放状态、边界数值和页面可访问性审计。

## 设计原则

- 战斗引擎不依赖 DOM，可以在浏览器、测试环境和未来服务端复用。
- 相同输入必须生成字节一致的序列化事件日志。
- 编队控制器只管理名单和站位，不直接操作页面或战斗引擎。
- 播放控制器负责阶段切换和定时调度，战斗引擎是战斗状态的唯一权威。
- 当前每场战斗必须包含三名不同学生，并完整占据 A1、A2、A3。

完整游戏规则见[游戏设计文档](docs/GAME_DESIGN.md)。
